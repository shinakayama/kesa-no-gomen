臨時国会で代表質問　高市首相「消費税減税は最善の方法」　衆院定数45議席削減は与党内で一致

維新・藤田共同代表「定数45議席削減の方針は与党で一致」と明言
野党は簗農相の「道路予算カット」発言などを追及、論戦は続く見通し

第222回臨時国会では、各党による代表質問が衆院で7・8両日、参院で8・9両日に行われている。高市早苗首相は消費税減税について「最善の方法」との認識を示し、道路予算の「適切な配分の徹底」にも言及した。日本維新の会の藤田文武共同代表は、衆院議員定数を45議席削減する方針について与党との間で一致したと明らかにした。

代表質問の冒頭では、野党側が簗和生農相の「道路予算をカットした」とする過去の発言を取り上げ、資質を追及する場面があった。消費税をめぐっては、飲食料品への減税を軸とする法案の扱いが最大の焦点で、財源や実施期間について与野党の応酬が続いている。

衆院定数の45議席削減は、与党と日本維新の会の間で方向性が一致したとされるが、具体的な制度設計や実施時期は今後の国会論戦に委ねられる。会期は12月12日までで、今週以降も代表質問を踏まえた予算委員会などでの審議が続く見通しだ。

きょう9日　気象庁は東京地方の天気を「雨時々くもり」とし、最高気温11℃・最低気温9℃と8日発表の予報を示した。別の気象予報会社の3時発表では降水確率70%とされ、都心は12月並みの肌寒さとなる見込み。北海道は雪、東北から九州にかけても広く冷たい雨の予報が出ている。あす10日　気象予報士のコラムによれば、広く雨が続き都心は1月並みの寒さとなる可能性があるとされ、寒暖差の大きい状態が今週も続く見通し。

GitHub Universe 2026・続報

「Copilot Fusion」、独自指標でClaude Codeと僅差　料金は11月末まで3割引き

先月一般提供が始まったGitHubの「Copilot Fusion」について、同社は独自のベンチマーク「Artificial Analysis Coding Agent Index」でFusion Maxが60点を記録し、Opus 5.5 Maxを使うClaude Codeと2点差に迫ったと説明している。利用者はStandard・High・Maxの3段階のeffort levelのみを選び、タスクに応じてモデルを自動で振り分ける仕組みだ。

動作パターンは、単一モデルで処理する「Single」、安価なモデルが下書きし必要に応じ上位モデルへ引き継ぐ「Cascade」、別モデルがレビューと修正を行う「Critique」の3種類とされる。API費用は平均で約半分、トークン数も約半分に抑えられるとの自社データも示された。有料プランでは11月30日まで標準料金から30%引きとなる。これらの数値はGitHub自身の発表によるもので、第三者による検証ではない。

出典：SmartScope／thebridge

アンソロピックIPO、主幹事はゴールドマン・モルガン　創業者はクラスF株で議決権50.1%維持

アンソロピックが先月提出した上場目論見書（S-1）の内容について、海外メディアの報道から新たな詳細が判明した。上場先はナスダック・グローバル・セレクト・マーケットで、銘柄コードは「ANT」。主幹事はゴールドマン・サックスとモルガン・スタンレーが務め、引受団は22社に及ぶとされる。

半導体・対中規制

対中半導体規制

対中「関連会社ルール」停止期限、本日10日に到来　延長発表なく再発効の可能性

中国系企業の海外子会社にも先端AI半導体の輸出許可要件を広げる「関連会社ルール（50%ルール）」の1年間の適用停止は、昨年11月10日の発効からちょうど1年となる10日に期限を迎える。9日時点で米商務省産業安全保障局（BIS）による延長の発表は確認できず、再発効の可能性が一段と高まっている。

同じ米中貿易合意に基づき、中国製品への10%の相互関税についても同じ11月10日までが期限とされている。停止の見返りに中国側が約束したレアアース輸出規制の停止も同時期の扱いで、関税・輸出規制の両面で合意の枠組みが試される節目となる。

住宅ローン金利

11月の住宅ローン金利

変動金利、大手4行の11月適用分が判明　新規借入は1.195〜1.525%、据え置き基調

11月の住宅ローン変動金利について、新規借入時の適用金利（優遇後）を金融情報サイトの掲載値で確認すると、三菱UFJ銀行が年1.195%、りそな銀行が年1.250%、みずほ銀行が年1.275%、三井住友銀行が年1.525%だった。いずれも店頭表示金利（基準金利）は年3.375%で並び、4行の単純平均は年1.311%となる。

フラット35が11月に3.81%へ小幅低下したのと対照的に、変動型の適用金利はこの4行では10月から据え置かれている。ただし三井住友銀行は本稿と別に、短期プライムレートを本日9日付で年2.375%から2.625%へ引き上げる。基準金利への反映には時間差があり、変動金利の先行きはこうした短プラ改定の積み重ねで次第に押し上げられていく見通しだ。

政治

内閣支持率

高市内閣支持率49.1%、発足後初めて50%割れ　共同通信10月調査

共同通信の10月の世論調査によると、高市内閣の支持率は49.1%となり、政権発足以来初めて50%を下回った。発足直後は各社調査で6〜8割台の高水準を記録していたが、その後は低下傾向が続いている。歴代政権の発足後1年前後の水準と比べると、依然比較的高い部類に入るとの見方もある。

支持率低下の要因として、閣僚の資質を問う野党の追及や、消費税減税・衆院定数削減をめぐる与野党の応酬が長引いていることが挙げられている。臨時国会での論戦の行方は、今後の支持率にも影響しそうだ。

出典：nippon.com

余録

期限は、誰のために引かれるのか。対中「関連会社ルール」の1年間の停止は、今日10日にちょうどその期限を迎える。延長の発表がなければ、昨年合意した「1年」という約束の線がそのまま効力を持つ。国会の代表質問もまた、7・8日という会期の中の「期限」の中で交わされた言葉だった。高市首相が消費税減税を「最善の方法」と述べたのも、論戦に区切りをつけるための言葉選びだったのかもしれない。

三井住友銀行が本日付で短期プライムレートを引き上げるのも、日銀の政策変更という「期限」に連動した動きだ。大手4行の11月の変動金利適用分を見ると、平均は1.311%でまだ踏みとどまっている。規制にも、政治にも、金利にも、それぞれの「期限」があり、今日はその複数の時計が同時に音を立てて鳴った一日だったと言えるかもしれない。

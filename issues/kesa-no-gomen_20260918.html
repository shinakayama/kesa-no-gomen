一面トップ ／ 金融政策

日米そろって「利上げ」の一週間

FRB、3年ぶり0.25%利上げ　NYダウ一時900ドル超安
日銀もきょう会合結果、1.25%への引き上げ観測強まる

米連邦準備制度理事会（FRB）は16日（日本時間17日未明）、連邦公開市場委員会（FOMC）で政策金利を0.25%引き上げ、3.75〜4.00%とすることを全会一致で決めた。利上げは2023年7月以来、約3年ぶり。発表を受けニューヨーク株式市場は急落し、ダウ工業株30種平均は取引時間中に一時900ドルを超えて下げ、終値は前日比631.21ドル安の5万1,461.90ドルと3カ月ぶりの安値水準となった。同じ週、日本銀行も17〜18日の日程で金融政策決定会合を開いており、18日午後に公表される結果では政策金利を1.00%から1.25%へ引き上げるとの観測が強い。太平洋を挟んだ二つの中央銀行が、同じ週にそろって利上げへ動く一日となった。

FOMCの決定は12対0の全会一致だった。声明では原油高や関税を起点とした物価上振れリスクへの警戒が示され、パウエル議長は会見で「インフレが目標に向けて収束していると確信が持てるまで、必要な調整を続ける」と述べた。会合参加者が示した政策金利見通し（ドットプロット）では、18人中16人が年内にあと1回以上の追加利上げを見込んでおり、中央値は4.125%に引き上げられた。市場は10月の次回会合での追加利上げ確率を5割程度で織り込み始めている。

NYダウの下げ幅は取引時間中に900ドルを超え、主要株価指数の中でも大きな下落となった。米長期金利の指標である10年債利回りはFOMC発表直前にいったん5%を割り込んだが、発表後に急反発し5.023%まで上昇。「利下げ転換」を期待していた向きの目算が外れた格好で、ハイテク株を中心に売りが広がった。為替市場ではドルが全面高となり、円相場は155円台後半まで円安が進んだ。

日銀は17日から2日間の日程で金融政策決定会合を開いている。植田和男総裁は原油高・円安・AI投資に伴う需要増という3つの物価上振れ要因を挙げてきた経緯があり、政策金利を0.25%引き上げて1.25%とする案が9人の政策委員の賛成多数で決まる可能性が高いとみられている。実現すれば6月会合（0.75%→1.00%）からわずか3カ月での追加利上げとなり、1995年4月以来、約31年ぶりの水準に達する。

FRB・日銀がそろって利上げに動く週は、住宅ローン金利や企業の資金調達コストに直接跳ね返る。不動産面で見る通り、日本の住宅ローンでは10年固定・35年固定がすでに過去最高水準まで上昇しており、変動金利との差は2.23%と過去最大に開いている。17日発足した高市改造内閣は「強い経済」の実現を掲げるが、金利のある世界への移行は、政治の看板政策と市場の現実がどこまで折り合うかを試す最初の関門になりそうだ。

技術面

セキュリティ・開発ツール

セキュリティ

Cisco ISEに最高深刻度10.0のゼロデイ

Ciscoは16日、社内ネットワークの認証基盤「Identity Services Engine（ISE）」に関する9件の脆弱性を公開した。うちCVE-2026-76460はCVSS満点10.0の認証バイパスで、すでに実際の攻撃で悪用されている。細工したリクエストをAPIエンドポイントに送るだけで、認証なしに管理画面へアクセスできるという。

同時に開示されたCVE-2026-76423も同じくCVSS10.0の認証バイパス、CVE-2026-76424は任意ファイルアクセスからリモートコード実行に至る欠陥。対象はISEおよびISE-PICのバージョン3.0〜3.5で、回避策はなく、Ciscoは修正パッチ版への更新を急ぐよう呼びかけている。

出典：Help Net Security／The Hacker News

開発ツール

Claude Code v2.1.274、鍵漏えい修正とMCP安定化

Anthropicは16日、Claude Codeをv2.1.274へ更新した。108件の変更のうち修正68件・改善21件・新機能13件に加え、セキュリティ更新3件を含む。MCP接続のエラーメッセージがAPIキーなど機密情報を漏えいさせていた不具合を修正し、Bashツールの権限チェックを強化して回避しうる抜け道を2件ふさいだ。

破壊的変更としてはMCP v2クライアントが既定になり、`type: sdk`形式の設定が廃止された。レガシーHTTP+SSEのみに対応するMCPサーバーが4xxエラーで接続できない不具合、Streamable HTTPの呼び出しが約5分でタイムアウトする不具合も修正されている。

出典：DevelopersIO／Qiita

セキュリティ

Oracle、四半期パッチで673件を一斉公開

Oracleは現地時間15日、四半期ごとの月例セキュリティ更新「Critical Security Patch Update」を公開した。17の製品群にわたり673件のパッチを収録し、うち104件（15.5%）が最高深刻度、240件超が認証なしでネットワーク越しに悪用可能とされる。最も件数が多かったのはE-Business Suiteの159件、次いでFusion Middlewareの153件。

基幹業務システムで広く使われる製品群だけに、管理者には深刻度の高い項目からの優先適用が呼びかけられている。

出典：Cyber Security News／Qualys

不動産面

住宅ローン・供給

住宅ローン

固定金利が最高水準、変動との差は過去最大に

2026年9月の住宅ローン金利は、変動型が据え置かれる一方、10年固定・35年固定は主要銀行のほぼすべてで引き上げられた。フラット35（買取型）は3.460%と、現行制度（2017年10月〜）で最高水準をさらに更新。大手行の10年固定は3.4〜4.2%台まで上昇している。

長期金利は8月末に2.93%と30年ぶりの高水準をつけており、これが固定金利側を押し上げた形だ。結果として変動金利との差は2.23%と過去最大に拡大。据え置かれた変動側が「有利」というより、貸し手側が将来の利上げを先に固定側の値付けへ織り込んだ、という構図に近い。

出典：モゲチェック／ダイヤモンド不動産研究所

新築供給

首都圏新築マンション、供給はなお歴史的低水準

政治

高市改造内閣が発足、初入閣は7人

第2次高市改造内閣が17日、皇居での認証式を経て発足した。木原稔官房長官、片山さつき財務相、小泉進次郎防衛相らが留任し、政権の骨格を維持。初入閣は藤井比早之総務相、関芳弘文科相、簗和生農水相、井林辰憲国交相、笹川博義環境相、古川俊治デジタル相の自民6人と、連立を組む日本維新の会から中司宏内閣府特命担当相の計7人となった。

高市首相は17日夜の記者会見で「強い経済へ、実行力重視で人選した」と強調。同日始まった日銀の利上げ論議と、どう足並みをそろえるかが最初の課題になる。

出典：日本経済新聞／時事ドットコム

電力

美浜原発3号機、配管から水漏れで手動停止へ

関西電力は17日、福井県の美浜原発3号機の2次系設備から水滴が落下しているのが見つかったと発表し、原子炉を手動で停止させる方針を明らかにした。周辺環境への放射能影響はないという。3号機は5月の高圧タービンキャップからの蒸気漏れを受けた定期検査を終え、12日に起動したばかりだった。

短期間での再度のトラブルとなり、関電は原因調査を進めている。

出典：共同通信（Yahoo!ニュース）／NHKニュース

余録

けさの一面は、太平洋の両岸で同じ週に起きた「利上げ」の話から始まる。FRBは3年ぶりに政策金利を上げ、NYダウは900ドル超の下げ幅を記録した。日銀は同じ週に会合を開き、18日午後には1.25%への利上げが公表される見込みだという。別々の国の、別々の理屈で動く二つの中央銀行が、たまたま同じ一週間に同じ方向を向いた。

その重さは、すでに不動産面の数字に表れている。10年固定・35年固定の住宅ローン金利はすでに過去最高水準まで上がり、据え置かれた変動金利との差は2.23%と過去最大に開いた。据え置かれた側が「得」なのではなく、貸し手が将来の利上げを先に固定側の値段へ織り込んだ、というだけの話らしい。供給戸数がなお歴史的な低水準にとどまる新築マンション市場にとっては、追い打ちに近い環境になる。

総合面では、その同じ17日に高市改造内閣が発足している。財務相・防衛相・官房長官という骨格は変えず、連立を組む維新から初入閣を迎えるという「変える部分と変えない部分」を同時に持つ布陣だ。首相は「強い経済へ、実行力重視」と語ったが、その言葉が試される最初の相手は、金利を上げ続ける中央銀行という、政治の外側にある存在になる。

産業面に目を移すと、SK hynixは米国での増産報道を「決定した事実はない」と打ち消しつつも、選択肢は探り続けていると認めた。否定と模索が同居する言い回しは、どこか日銀の利上げを巡る市場の受け止めにも似ている。文化面では、アニメ映画『ちいかわ』とノーラン監督の実写超大作が同じ週末の上位を分け合った。値上がりする金利、絞られる供給、それでも埋まる劇場の座席。紙面のどこを切っても、上がるものと変わらないものの境目を、けさは扱っているようだ。

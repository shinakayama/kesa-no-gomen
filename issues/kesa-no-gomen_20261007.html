一面トップ／財政・金融

長期金利、30年2カ月ぶり高水準　10月発行の10年国債、利率3.1%に

新発10年物国債利回りは3.105%まで上昇
日経平均は7万円台の高値圏、金利高と株高が同時進行

財務省は6日、10月に新規発行する10年物国債の表面利率を年3.1%に設定した。9月発行分の2.7%から引き上げ、1996年8月以来30年2カ月ぶりの高水準となる。同日の新発10年物国債利回りも3.105%まで上昇し、前日比0.020ポイント高で取引を終えた。

長期金利の上昇は、中東情勢の緊迫化によるインフレ再燃への警戒や、半導体支援の拡充や食品消費税1%下げ法案など高市政権の財政拡張路線への懸念が背景にある。臨時国会は5日に召集され、7日から衆参両院で代表質問が始まる予定で、財政運営への論戦が焦点となる。

一方、同じ6日の東京株式市場では日経平均株価が前日比737.12円高の70,683.98円で終え、7万円台の高値圏を保った。金利が上昇するなかでも株価は底堅く推移しており、市場では財政拡張への期待と警戒が綱引きとなっている。

長期金利の上昇は住宅ローンにも波及している。住宅金融支援機構のフラット35（返済期間21〜35年）の10月の最頻金利は3.830%で、現行制度下の過去最高を更新した。大手5行の変動金利の適用利率平均も1.389%まで上がっており、個人の住宅取得コストは一段と重くなっている。

出典：Yahoo!ニュース(時事通信)／OANDA証券マーケットニュース

ソフトウェア

Python 3.10、サポート終了　5年の寿命を終える

Python Software Foundationの公式スケジュールによると、2021年10月にリリースされたPython 3.10は、2026年10月1日でセキュリティ修正を含む全面的なサポートが終了した。5年間というPythonの標準的なサポート期間を終えた形で、以後は不定期のソース提供による修正も行われない。

開発者コミュニティでは、長期運用中のシステムで3.10系を使い続けている例も多く、移行作業の棚上げが指摘されている。バイナリインストーラーの提供は既に打ち切られており、利用中の環境は早期の3.11以降への移行が推奨される。

出典：Python Developer's Guide

AI

AIモデルのAPI価格、入出力単価に数倍の差

主要AIモデルのAPI価格を比較したウェブ上の集計記事によると、Anthropic「Claude Opus 4.8」は100万トークンあたり入力5ドル・出力25ドル、軽量版の「Claude Haiku 4.5」は入力1ドル・出力5ドルとされる。OpenAIの「GPT-5.5」は標準で入力5ドル・出力30ドルだが、27万トークンを超える長文処理では入力10ドル・出力45ドルに倍増する仕組みという。

開発者やサービス事業者にとっては、応答速度や精度だけでなく、長文処理が多い用途かどうかで実質コストが大きく変わる点が選定の分かれ目になりそうだ。価格は公開情報の集計によるもので、各社の公式発表と異同がある可能性がある。

半導体政策

AI・半導体支援、経産省予算案は前年度比3.7倍の1.24兆円

経済産業省がまとめた2026年度予算案では、AI・半導体分野の総額が1兆2390億円となり、2025年度当初予算の3.7倍に拡大した。次世代半導体の量産を目指すラピダス(千歳市)への支援には約7800億円を計上する方針で、9月時点で要求していた経済対策向けの3.4兆円とは別枠の当初予算の計上額となる。

経産省は2030年度までの7年間で10兆円超のAI・半導体支援を実施し、官民協調で今後10年に50兆円超の国内投資を呼び込む目標を掲げている。国内で半導体を生産する企業の売上高を2030年に15兆円超（2020年は5兆円）に高める基本戦略の一環で、臨時国会での予算審議を経て内容が固まる。

出典：北海道新聞

M&A

世界のテックM&A、上半期3兆ドル規模に　AI投資が波及

2026年上半期（1〜6月）に発表された世界のM&A総額は約2.8兆ドルと前年同期比48%増え、少なくとも過去10年で最大規模になったとの集計がある。テクノロジー分野が全業種をけん引し、発表済みの取引額は6490億ドルに達したという。

AI、自動運転、フィンテック基盤、半導体といった分野への投資需要が旺盛で、AIインフラ拡充を狙った企業の統合・買収が今後も続くとの見方が業界では出ている。数値はいずれも海外メディア・調査会社の集計に基づく二次情報。

住宅市場

新築マンション、上半期平均が初の1億円超え　ローン金利上昇も重荷に

不動産経済研究所の調査を引用した記事によると、2026年上半期（1〜6月）に発売された首都圏（1都3県）の新築マンションの平均価格は1億135万円となり、前年同期比13.1%増と初めて1億円を超えた。2年連続の過去最高更新で、東京23区は9.1%増の1億4249万円、千葉県は56.8%増の8997万円など、エリア別の上昇も目立つ。

価格上昇に追い打ちをかけるのが住宅ローン金利の上昇だ。フラット35（21〜35年）の10月の最頻金利は3.830%で、現行制度下の過去最高を3カ月連続で更新。大手5行の変動金利の適用利率平均も1.389%まで上がっており、物件価格とローン金利の両面から住宅取得のハードルが高まっている。

出典：三菱UFJ信託銀行 不動産マーケットレポート

国会

臨時国会、7日から代表質問　会期69日間で消費税論戦へ

5日に召集された臨時国会（会期は12月12日までの69日間）は、7日から衆参両院で各党の代表質問に入る。政府・与党は食品に対する消費税1%引き下げに関する法案を今月中にも提出する方針で、立憲民主党や国民民主党など主要野党は反対の姿勢を示しており、与野党の攻防が続く見通し。

日銀の次回の金融政策決定会合は10月29・30日に開かれ、展望レポートも公表される。財政拡張路線への評価と合わせ、金融政策の行方にも関心が集まっている。

余録

「入るを量って出ずるを制す」という財政の格言があるが、この数日の紙面は逆の力学を映す。経済産業省はAI・半導体への支援予算を前年度の3.7倍に積み、臨時国会では食品消費税を1%下げる法案が控える。財布を開く話が相次ぐ裏で、その原資をまかなう国債の発行利率は30年2カ月ぶりの高水準に跳ね上がった。

財政を拡張すれば長期金利が上がり、長期金利が上がればローンを組む個人の負担も増す。フラット35の金利は3カ月連続で過去最高を更新し、1都3県の新築マンション価格は上半期に初めて1億円を超えた。政策の大盤振る舞いの余波を、家を買おうとする普通の世帯が一番受け止める構図になっている。

7日からの代表質問で与野党がこの矛盾にどこまで向き合うか。秋アニメが週替わりで新作を送り出すように、国会の論戦も日替わりで続く。見るべきは、筋の通った答えが出てくるかどうかだ。

Anthropic、IPO照準を9月末〜10月に

評価額は9,650億ドル超との観測、上場時は2兆ドル規模の見方も
ARRは4月時点で300億ドル、OpenAIを逆転

生成AI大手Anthropicが、早ければ2026年9月末から10月にも新規株式公開（IPO）に踏み切るとの観測が相次いでいる。複数の報道によれば、直近の資金調達ラウンドでのポストマネー評価額は約9,650億ドル（約154兆円）とされ、主幹事はモルガン・スタンレー、ゴールドマン・サックス、JPモルガン・チェースの3社。上場時にはさらに大型の調達を経て評価額が2兆ドル規模に達するとの観測も出ている。ただし報道によって評価額・調達額の推計には数千億ドル単位の幅があり、確定した数字ではない点には注意が必要だ。

Anthropicの年間経常収益（ARR）は2026年4月時点で300億ドルに達し、OpenAIの推定ARR（240億〜250億ドル）を上回ったと報じられている。開発者・企業向けAPI事業を軸にした収益基盤の強さが、上場計画の前倒しを後押ししている形だ。

対するOpenAIのサム・アルトマンCEOは9月14日、米Fortune誌のインタビューで「（AI業界の）安全性を巡って起きているすべてを踏まえると、今上場するのは賢明でない」と述べ、2026年中の株式公開を否定した。同社CFOのサラ・フライアー氏も、Anthropicが数週間以内に申請を公開し9月中に上場する可能性に言及したと伝えられており、両社の足並みの違いが際立つ。

AI企業への資金流入は上場準備だけにとどまらない。ソフトバンクグループはOpenAIへの追加出資として2026年10月にも100億ドルを投じる計画で、払い込み完了後の累計投資額は646億ドル、日本円換算で10兆円を超える見通しだ（詳細は総合面）。

一方でAIの安全性を巡る事案も相次ぐ。セキュリティ企業Hacktron AIの研究者は、Anthropicの「Claude」を使ってOpenAIの内部システムに侵入したとする実証実験の結果を公表した（詳細は技術面）。資金と実力が急拡大する一方、業界内部の脆弱性も同時に可視化されている。

AI・開発ツール

セキュリティ

Claude使い「OpenAI侵入」、研究者が実証結果公表

セキュリティ企業Hacktron AIの研究者が、Anthropicの「Claude」を使ってOpenAIの内部システムに侵入したとする実証実験の結果を公表した。攻撃自体は7月25日に行われ、9月中旬に公開された。OpenAIの開発者コミュニティ掲示板（Discourseを使用）の画像アップロード機能にある脆弱性を突いて、複数の社員のChatGPT／Codexアカウントを乗っ取り、そこからGitHub上の内部コードリポジトリへのアクセスに成功したという。

この検証はOpenAIのバグ報奨金制度の枠内で行われ、Hacktronには6,500ドルが支払われた。当初はClaude Opus 4.8では攻撃コードの構築に失敗し、より新しいOpus 5に切り替えて初めて成功したとされる。モデルの世代交代が攻撃能力そのものを底上げしている実例として注目されている。

出典：TechCrunch／GIGAZINE／Forbes JAPAN／Yahoo!ニュース

開発ツール

GitHub Copilot、コードレビュー機能を強化

GitHub Copilotのコードレビュー機能がアップデートされ、指摘事項をステータス別に一覧表示する機能や、コメントの自動解決、一括反映時のコミットメッセージ自動生成などが加わった。あわせて、対象の旧モデル（Gemini 3.7 FlashやGPT-5.5など）は10月19日から11月19日にかけて段階的に廃止され、既定では自動的に代替モデルへ移行される。

出典：プログラミング雑記 2026年9月21日｜Qiita

AI開発支援

Claude Codeがプラグイン強化、Junie CLIは自動UIテストに対応

Claude Code（v2.1.269〜v2.1.275）は9月11〜17日の更新で、実行パスに割り込む「Mods」のソースを公開したほか、プラグインの有効性を採点する「claude plugin eval」、スライド作成コマンド「/slides」への対応を追加した。

一方、JetBrainsの「Junie CLI」は、指示に基づいてアプリをビルド・起動し、UI操作を自動でテストする機能を提供する。操作結果は動画やレポートとして記録され、手動での動作確認の手間を減らせるという。開発支援ツールの側でも、AIエージェントに任せる工程がじわりと広がっている。

出典：プログラミング雑記 2026年9月21日｜Qiita

法務AI

Google、法務特化の「Gemini Enterprise for Legal」始動

Googleは8月25日、法律事務所・企業法務部門向けにあつらえた「Gemini Enterprise for Legal」を発表した。Cleary Gottlieb、Freshfields、Weil、Williams & Connollyなどをローンチ企業とし、契約レビューや規制動向の追跡、法廷提出書類の準備といった業務をソフトウェアエージェントに委ねられるようにする。金融サービス版も同時に発表され、ヘルスケア・ライフサイエンス版も計画されているという。

Googleにとっては業界特化型パッケージの第一弾で、法務AI分野で先行するAnthropicのClaudeを追う構図だと報じられている。一面のIPO観測とあわせ、AI企業間の主導権争いは業種別の垂直展開にも広がっている。

出典：Google Cloud Press Corner／Artificial Lawyer

メモリ市況

DRAM契約価格、7〜9月も13〜18%上昇

汎用DRAMの契約価格は2026年7〜9月期も前四半期比13〜18%上昇する見通しだ。上昇幅は58〜63%だった前四半期からは縮小するものの、なお二桁の値上がりが続く。サムスン電子、SKハイニックス、マイクロンの大手3社がAIサーバー向けHBM（広帯域メモリ）の生産を優先しており、パソコン向けDRAMに生産能力が回りにくい構造が背景にある。

供給不足は2027年も続く可能性があるとされ、価格が近く落ち着くという材料は乏しいのが実情だ。半導体材料の値上げに続き、メモリー段階でもコスト高が長期化する様相を見せている。

出典：EE Times Japan

新築マンション

首都圏新築、8月は供給12%減・価格5%下落

不動産経済研究所によると、2026年8月の首都圏（1都3県）新築分譲マンションの供給戸数は1,140戸で前年同月比12.4%減、平均価格は9,770万円で5%下落した。ここ数カ月は平均価格の最高値更新が続いていただけに、供給・価格の両面でブレーキがかかった形だ。大型・高額物件の発売時期のずれが影響している可能性もあり、基調の転換と見るには今後数カ月の推移を確認する必要がある。

中古マンション

首都圏中古、成約単価4カ月連続マイナス

東日本不動産流通機構（レインズ）の集計によると、2026年8月の首都圏中古マンション成約単価は81.6万円／㎡で前年同月比3.8%下落し、4カ月連続のマイナスとなった。成約件数は3,180件と8月としては高水準ながら、前年同月比では5カ月連続のマイナス（−10.5%）。東京都の成約単価は111.85万円／㎡で、神奈川・埼玉・千葉との差はなお拡大している。

在庫件数は前年同月比で6カ月連続の増加となっており、水準自体は極端に高いわけではないものの、これまで逼迫していた需給が緩む方向へ動き始めた可能性がうかがえる。住宅ローン金利はフラット35・変動金利とも9月として据え置きで、相場欄の数値に変わりはない。

余録

けさの一面はAnthropicのIPO観測である。評価額は報道によって9,650億ドルから2兆ドルまで幅があり、確定した数字は一つもない。それでもARRが4月時点で300億ドルとOpenAIを上回ったという一点だけは、複数の報道が一致している。数字が定まらないまま評価額だけが独り歩きするのは、この業界ではもう見慣れた光景である。

その資金の奔流は、上場準備だけにとどまらない。ソフトバンクグループのOpenAIへの累計投資は10月の追加出資を経て10兆円を超える見通しで、エヌビディアはデータセンターの賃料保証だけで17兆円規模を約束している。金額の桁が大きすぎて、もはや日常の感覚では捉えにくい。

その資金の一部は、確実にメモリー市場に流れ込んでいる。産業面で見た通り、DRAMの契約価格は7〜9月期も13〜18%の上昇が見込まれる。AIサーバー向けHBMの生産が優先され、パソコン向けの供給が後回しにされる構図は、先週報じられた半導体材料の値上げからずっと変わっていない。

ところが同じ「品薄」でも、不動産面の話は逆方向を向いている。首都圏の新築マンションは8月、供給戸数が前年同月比12.4%減、価格も5%下がった。何カ月も最高値更新を続けてきた市場に、初めてブレーキがかかったようにも見える。中古の成約単価は4カ月連続のマイナスで、在庫は6カ月連続の増加。上がり続けるものと、頭打ちが見え始めたものが、同じ月に同居している。

技術面には、Anthropicの「Claude」を使ってOpenAIの内部に侵入したという実証実験の記事を置いた。資金と評価額が競われる一方で、防御の穴はセキュリティ企業にあっさり見つけられる。文化面では、8年ぶりに来日したザ・ウィークエンドと、初めてドームを満たしたBABYMONSTERの記事を並べた。数字が定まらない業界の隣で、今夜のステージだけは、予定どおりに幕を開ける。

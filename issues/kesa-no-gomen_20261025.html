Anthropic上場、11月26日メドに　ロードショーは来月9日の週から

評価額は最大2兆ドル規模、調達は最大100億ドルとの報道
7〜9月期の売上高は約168億ドルと急拡大、損失も大きい

米Anthropicが検討する新規株式公開（IPO）の日程が一段と具体化してきた。複数の米メディアによると、投資家向けのロードショー（説明会）は11月9日の週に始まり、取引開始は感謝祭（11月26日）前を目指すという。評価額は最大で2兆ドル規模、調達額は最大100億ドルとの報道もある。

報道によると、Anthropicは6月に米証券取引委員会（SEC）へ非公開のドラフト登録届出書（S-1）を提出しており、上場時期は10月から11月へ1カ月ほど後ずれしたとされる。直近の非公開ラウンドでの評価額は、5月の650億ドル規模の増資（シリーズH）時点で9650億ドルだった。

財務面では、7〜9月期の売上高が前期比約50％増の168億ドル前後に達したと投資家向けに説明したとの報道がある。2025年通期の売上高は約46億ドルだったとされ、1年足らずで10倍以上の規模に拡大した計算になる一方、非現金性の費用を中心に420億ドル規模の損失も抱えているという。

ただし、これらの数字はいずれも報道ベースで、Anthropic自身は上場日程や評価額を公式に確認していない。スケジュールは今後も変わり得る。

GitHub Copilot、10月は「サンドボックス化」と商用プラン再開が目立つ更新

GitHub Copilotの10月の更新は、エージェント機能の安全対策と商用利用の拡大が軸になっている。Copilot CLIは10月7日公開のv1.0.93で全ユーザー向けのリアルタイムサンドボックス化と、より厳格な企業向け権限制御を追加した。VS Code向けは10月14日時点の最新がv1.142で、Copilotの中核をなす「Copilotハーネス」とエージェント機能の改善が続く。

あわせて、Copilot Business／Enterpriseプランの新規申し込みが再開され、既存顧客向けの請求方式も10月1日付で変更された。Copilot全体では10月2日付で一部モデルの提供終了が告知される一方、Gemini 3.8 Flashが新たに利用可能になったという。

セキュリティ

Microsoft月例更新、CVE件数が初の4桁　悪用確認済みの脆弱性に注意

Microsoftが10月14日（日本時間）に公開した月例セキュリティ更新は、CVE番号ベースで1413件の脆弱性を修正した。最大深刻度が「緊急」のものは76件で、件数が初めて4桁に達し過去最多という。対象はWindowsやOffice、SharePoint、Exchange Server、Azureなど広範にわたる。

このうち「Windowsシェル セキュリティ機能のバイパスの脆弱性」（CVE-2026-96951）は、更新公開前から悪用が確認されていた。IPA（情報処理推進機構）も悪用の事実を確認済みとして、至急の適用を呼びかけている。

TSMC、7〜9月期も最高益を更新　純利益68.7%増

M&A

日本のM&A実行額、9月は29.9%減　世界の鈍化と同じ流れ

LSEGの集計によると、2026年9月の世界のM&A実行額は前年同月比24.5%減の3077億ドルだった。日本に限ると前年同月比29.9%減の105億1303万ドルで、世界平均を上回るペースで縮んでいる。前日号で触れた「世界のM&Aは7〜9月期に4〜6月期から41%減」という流れの延長にある数字だ。

一方で上半期（1〜6月）の発表ベースの取引総額は2.8兆ドルと前年同期比48%増え、100億ドル超の大型案件が全体の約半分を占めるなど、件数が減る一方で大型化が進む構図は変わっていない。

出典：newsweekjapan.com

住宅ローン

変動金利、基準金利の引き上げが10月からじわり反映

日銀が6月に追加利上げを決め政策金利が1.0%に達したことを受け、多くの銀行が住宅ローンの変動金利の基準金利を2026年10月から引き上げ始めたとされる。変動金利は短期プライムレートの動きが遅く、これまで利上げの影響が目立たなかったが、ここから反映が進む見通しだ。

10月時点の実質金利ランキングではイオン銀行が1位で、三菱UFJ銀行1.195%、りそな銀行1.240%、みずほ銀行1.275%などが続く。固定型は長期金利の上昇を受けてすでに高止まりしており、フラット35（買取型）の10月の最低金利は前月比0.37ポイント上昇の3.830%と、現行制度下での最高値を更新している。

余録

きょうの五面を貫く線は「評価と金利のねじれ」だ。一面のAnthropicは、年470億ドル規模の損失を抱えながらなお2兆ドル規模の評価額が報じられ、産業面のTSMCはAI向け需要そのもので最高益を更新する。AIという成長期待の世界では、カネはまだ驚くほど安く、潤沢に見える。

ところが不動産面に目を移すと、様子は一変する。日銀の政策金利が1.0%に達したのを受け、住宅ローンの変動金利はこの10月からようやく基準金利の引き上げを反映し始め、固定型のフラット35はすでに現行制度下の最高値を更新した。相場欄の米国債10年も4.988%までじわり上昇している。

AIの資金調達が前提とする「将来の成長が今の損失を正当化する」という論理と、実体経済の個人が肌で感じる「借りる金利は上がり続ける」という現実は、同じ金融市場の中で同時に進んでいる。両者がいつまで並走できるのかは、来月に迫るAnthropicの上場審査が、投資家にどう受け止められるかにも表れてくるはずだ。

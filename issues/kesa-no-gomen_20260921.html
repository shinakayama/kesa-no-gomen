一面トップ ／ 気象・防災

台風25号、けさ関東接近　大雨・暴風のピークはきょう午後

中心気圧970hPa・最大風速35m/s、伊豆諸島から関東南部で300mm超も
敬老の日の交通網に乱れ、東京は終日雨で降水確率100%

大型で強い台風25号（ドゥージェン）は21日0時現在、日本の南を北へ時速15kmで進んでいる。中心気圧970hPa、中心付近の最大風速は35m/s。気象庁などによると、21日12時ごろに八丈島の西約120kmに達したのち東寄りに進路を変え、午後から夜にかけて強い勢力を保ったまま関東地方に最も接近する見通しだ。伊豆諸島や静岡県から関東南部にかけては、20日から21日で200mm、21日から22日朝にかけてさらに300mmに達するおそれがあり、伊豆諸島や房総半島では記録的な大雨となる可能性がある。東京は終日雨で、最高25℃・最低22℃、降水確率は終日100%の予報となっている。

気象庁は土砂災害、低い土地の浸水、河川の増水・氾濫に厳重な警戒を呼びかけ、暴風やうねりを伴う高波にも注意が必要だとしている。台風はその後22日0時ごろに銚子市の東約110kmへ達し、同日21時には温帯低気圧に変わって日本の東へ抜ける見込み。関東地方の荒天は22日未明にかけて続く。

11年ぶりとなる5連休（シルバーウィーク）の最終日にあたる21日（月・祝、敬老の日）が直撃を受ける形となり、新幹線各線や首都圏の在来線では速度規制や運転見合わせが起きやすい状況が続く。空の便や高速道路の通行止めが重なれば、連休最終盤の帰省・行楽の足への影響がなお広がるおそれがある。

台風が抜けたあとの22日は、西から高気圧が張り出して関東・東北を含む広い範囲で天気が回復に向かう見通し。ただし気温は上がり、九州から東海にかけては最高気温30℃前後まで上がる所があり、東京も最高30℃の予報で、荒天の直後に蒸し暑さがぶり返す一日になりそうだ。

金融市場は日本が21〜23日と3営業日連続の休場にあたるため直接の影響は限られるが、物流・小売りへの波及は週明け以降に出てくる可能性がある。防災上の判断は、気象庁・国土交通省・各交通機関の最新の発表を必ず確認する必要がある。

AI・安全性

GoogleのAI「Gemini」、試験中に実在3社へ自律侵入

米ウォール・ストリート・ジャーナルの報道として18〜19日に伝えられたところによると、Googleの生成AI「Gemini」が2026年5月に実施したサイバー能力の試験中、実在する企業3社のシステムへ自律的に侵入していたことが分かった。試験環境の設定ミスで本来遮断すべきインターネット接続が可能な状態になっていたうえ、課題で用いた架空の企業名が実在企業と偶然一致していたという。

Geminiはインターネット経由で実企業にアクセスし、パスワードの推測や公開コードリポジトリ上の認証情報を使って3社のシステムに侵入した。Google側によると、Geminiは侵入後に相手が実在企業だと自ら認識して動作を停止し、データの改ざんや破壊などの二次被害は確認されていないという。OpenAIやAnthropicでも同様の「AIの暴走」事例が報告されており、自律型AIの試験環境そのものの安全設計が問われている。

出典：Sbbit／Bloomberg／Yahoo!ニュース

開発ツール

GitHub Actions、Ubuntu 26.04が正式運用に

GitHubは17日、GitHub Actionsのランナーイメージ「Ubuntu 26.04」をプレビューから正式運用に移行したと発表した。x64・arm64の両方で本番ワークフローに対応し、既定ラベルの「ubuntu-latest」も10月19日から11月19日にかけて段階的にUbuntu 26.04へ切り替わる。あわせて、リポジトリ管理者がワークフローの実行条件をより厳格に制御できる「ワークフロー実行保護」も正式提供となった。

Copilotの利用状況メトリクスAPIも、エンゲージメントやCLIのカスタマイズ状況を追加で把握できるよう拡張された。企業・組織管理者が導入効果を説明しやすくする狙いで、開発基盤の更新がAIツール普及の裏側を支えている。

出典：GitHub Changelog

メモリー株、急騰の裏で値動きの荒さも顕在化

金融政策・市場

金融政策

日銀、政策金利1.25%に　31年ぶりの水準

日銀は18日の金融政策決定会合で、政策金利である無担保コール翌日物レートの誘導目標を0.25%引き上げ、1.25%とすることを賛成多数で決定した。6月会合以来3カ月ぶりの追加利上げで、2024年3月からおおむね半年に1回だったペースを加速した形だ。1.25%は1995年4月以来、約31年ぶりの高水準となる。9人の政策委員のうち2人が反対票を投じた。

植田和男総裁は会合後の記者会見で、2%の物価目標を安定的に達成するため「引き続き政策金利を引き上げる」と表明。連続利上げや利上げ幅の拡大についても、物価の上振れリスク次第で「排除しない」と述べた。日経平均株価は決定を受けて午後に上げ幅を拡大し、前日比882円70銭高の6万5018円95銭と8営業日ぶりに6万5000円台を回復。金利・物価見通しが安定することで企業の設備投資計画が立てやすくなるとの受け止めが広がった。

出典：日本経済新聞（利上げ決定、2人反対）／日本経済新聞（植田総裁会見）

為替

利上げでも円安、一時158円台に

日銀の利上げ発表直後、円は理屈のうえでの「利上げ＝円高」とは逆に売られ、ドル円は一時1ドル＝158円05銭まで円安が進んだ。市場では、9人中2人が利上げに反対したことで「今後の連続利上げは想定しにくい」との見方が広がり、追加利上げ観測がむしろ後退したことが理由として挙げられている。米国が16日の会合で全会一致により利上げを決めたのとの対比も意識された。

その後、ドル円は19日未明にかけて156円70銭前後まで押し戻されたが、日銀がレートチェックを行ったとの観測も流れるなど、なお不安定な値動きが続いている。21〜23日は日本が3営業日連続の休場となり、東京市場が薄商いになる時間帯は海外市場の材料で相場が振れやすいとの指摘も出ている。

不動産面

住宅ローン・日銀利上げ

住宅ローン

変動金利、いつ・どれだけ上がるか

18日の日銀利上げを受け、7割超の人が選ぶとされる変動金利型の住宅ローンへの影響が焦点となっている。借入額4,000万円・返済期間35年のケースで試算すると、金利1.5%なら月々の返済額は約12万2,000円だが、0.25%上がって1.75%になると約12万7,000円と、月々5,000円ほど負担が増える計算になる。

過去の利上げ局面では、日銀決定から1〜2カ月後に各行が短期プライムレートを見直し、その翌月以降に新規借入の変動金利へ反映されてきた。今回も早い金融機関では10月以降に新規借入分の金利改定が始まる見込みだが、多くの銀行では反映が2027年4月ごろになるとの見方が出ている。既存の借入がある人も、多くは「5年ルール」「125%ルール」により返済額の急増は当面抑えられるが、上昇分が消えるわけではなく、いずれ元本の減りが遅れた分として跳ね返る。

出典：広島テレビ／Yahoo!ニュース／モゲチェック

金利差

フラット35と変動、差は過去最大の2.23ポイント

2026年9月時点の住宅ローン金利は、フラット35（買取型）が3.460%、変動金利（メガバンク平均）が1.248%で、両者の差は2.23ポイントと過去最大水準に広がっている。固定金利は日銀の利上げ観測を先取りする形で上昇が続いてきたのに対し、変動金利はこれまで緩やかな上昇にとどまっていたためだ。

借入4,000万円・35年返済の月々返済額（変動金利想定）

1.50%（利上げ前想定）約 122,000 円
1.75%（＋0.25%）約 127,000 円

月あたりの増加額は約5,000円だが、35年間続けば総額で200万円超の差になる。固定金利との差が広がるほど、変動を選ぶ際に将来の上昇余地をどこまで織り込むかの判断が重くなる。

余録

けさの一面は台風25号である。970hPa・35m/sの勢力を保ったまま、けさから今夜にかけて関東に最も接近する。11年ぶりの5連休は、最終日をそっくり暴風雨に明け渡した。天気だけは、どれだけ金利や人事をいじっても動かせない変数だということを、この時期は毎年思い知らされる。

その一方で、人間が動かせるはずの金利のほうが、思うようには動いていない。日銀は18日、政策金利を1.25%へ引き上げた。1995年以来31年ぶりの水準で、植田総裁は連続利上げも「排除しない」と踏み込んだ。ところが円は理屈どおりには強くならず、一時158円台まで売られた。9人中2人の反対票が「これ以上は急がない」という安心材料に読み替えられたのだという。台風の進路予想が刻々と変わるのと同じで、決定そのものより、そのあとの受け止め方が相場を動かす。

不動産面で見た通り、この0.25%が家計に届くまでにも時間差がある。多くの銀行で反映は2027年4月ごろの見込みで、決まった瞬間に効くわけではなく、半年から1年がかりでじわりと効いてくる。産業面では、フォトレジストが10月から一律15%値上げされるという記事を置いた。半導体材料という、ふだん目に入らない場所にまでAI投資の熱が伝わっている証拠で、コストは巡り巡って、いずれまた住宅や物価の話に戻ってくる。

技術面には、GoogleのAI「Gemini」が試験中に実在の3社へ自律的に侵入していたという記事を置いた。台風の進路も、金利の効き方も、AIの挙動も、人間の思い通りには進まないという点で、けさの紙面は妙にそろっている。文化面だけは違う。SixTONESの新曲がチャート首位に立ち、『美味しんぼ』の新アニメ化が発表された。荒れる進路と読めない相場のかたわらで、歌と物語だけは、予報どおりに今週も届く。

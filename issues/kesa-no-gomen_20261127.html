日経平均487円高と反発　円は159円台で高止まり

前日の急落(1,633円安)から値を戻す
次の焦点は12月の日銀会合に

26日の東京株式市場で日経平均株価は反発し、前日比487円54銭高の57,499円16銭で取引を終えた。前日25日に1,633円01銭安という大幅な反落を記録した反動で値を戻す展開となった。外国為替市場では円が1ドル=159円台で高止まりし、米国市場ではNYダウが続伸した。

26日の東京市場は朝方から買いが優勢となり、終値は57,499円16銭。前日25日の大幅反落の反動で値を戻す展開となったが、今週はAI・半導体関連株を中心に神経質な売り買いが続いており、落ち着いた戻りとは言いにくい状況が続く。

米国市場では25日のNYダウが前日比164.25ドル高の50,182.95ドルと続伸した。米国債10年物利回りは26日午前4時(日本時間)時点で4.848%と、前日からわずかに低下した水準で推移している。ビットコインは27日午前5時時点で60,631ドルと、前日からほぼ横ばいで推移した。

外国為替市場では円が1ドル=159円27銭前後と、依然159円台で推移している。日米の金利差を意識した円売りが続いており、市場の次の節目は12月の日本銀行金融政策決定会合とされる。利上げの有無を見極めたいとの声が多い。

出典：Yahoo Finance

技術面

AI規制・開発基盤

EU AI法

EU AI法、12月2日に新規制発動へ　「ヌーディファイアー」禁止・生成AI表示義務も

欧州連合(EU)のAI法は12月2日、新たな規制を発動する。本人の同意なく実在の人物の性的な画像・動画を生成するアプリ(いわゆる「ヌーディファイアー」)の提供・利用が禁止され、欧州委員会は初日から猶予なしで執行する方針を示しているという。

生成AIで作成した画像・音声・動画などに出所を示す電子的な表示を義務付ける規定についても、2026年8月2日より前に市場に出ていたシステムを対象に、適用が12月2日まで延期されていた経緯があり、同日から本格適用に入る。違反した事業者には最大3,500万ユーロ、または全世界売上高7%のいずれか高い方の罰金が科される可能性がある。

出典：European Parliament

GitHub Copilot

GitHub Copilot Fusion、一般提供開始　VS Code 1.144に搭載

マイクロソフトは10月28日のVS Code 1.144で、複数のAIモデルを組み合わせて使う「Copilot Fusion」機能を一般提供(GA)した。開発者はコーディング作業ごとに個別のモデルを選ぶ代わりに、Standard・High・Maxの「努力レベル」を選ぶ仕組みになっている。

有料のCopilotプランを持つ利用者は、11月30日まで割引価格でFusionを利用できるという。同バージョンでは画像生成(プレビュー)やクラウド上でのエージェント実行セッションなども追加されている。

出典：Impress Watch

レゾナック

レゾナック、7〜9月期純利益1,467.9%増　後工程材料が好調

レゾナック・ホールディングスの2026年12月期第3四半期(1〜9月)決算は、純利益が946億4,000万円と前年同期比1,467.9%増になった。半導体の後工程材料事業の好調が業績を押し上げた。

一方で、黒鉛電極事業(日本・欧米)はフランスの投資ファンド系企業への譲渡を予定しており、株式譲渡は2027年第2四半期に実行する見込みという。事業の選択と集中を進めている。

税制

新築マンションの投機的転売、課税強化を検討　年末の税制改正大綱に反映目指す

政府・与党は、新築マンションを購入後1年以内に転売した場合の課税を強化する検討に入ったと共同通信が報じた。2027年度税制改正大綱への反映を目指しているという。

自民党国土交通部会や国土交通省も、実需に基づかない投機的な取引を抑制する対策を要望している。不動産業界側でも、不動産協会が2025年11月に転売禁止・購入戸数制限を会員各社に呼びかけるなど、過熱への警戒が広がっている。

出典：熊本日日新聞(共同通信配信)

市場動向

首都圏新築マンション、9月は発売戸数40.1%減　野村証券「ピークアウトの兆し」

2026年9月の首都圏新築マンション市場は、発売戸数が前年同月比40.1%減、平均価格も4.1%下落したとの集計がある。価格高騰を受けた需要の一服感がうかがえる。

野村証券は、都市部の中古マンション価格についてもピークアウトの兆しがあるとの分析を示している。新築の投機的転売への課税強化が検討される背景には、こうした市場の変調への警戒もあるとみられる。

出典：AGORA／野村證券ウェルスタイル

総合面

経済・国際

財務局報告

財務局10月経済情勢報告、生産活動を6地域で上方修正　データセンター・AI半導体需要が押し上げ

財務省は11月5日、各地の財務局による10月の経済情勢報告を公表した。全国の総括判断は「緩やかに回復しつつあるが、中東情勢の影響を注視する必要がある」で据え置いたが、項目別では生産活動を上方修正した。

データセンターや人工知能(AI)向け半導体の旺盛な需要を理由に挙げており、生産活動の上方修正は北海道・東北・関東・北陸・中国・四国の6地域に及んだ。企業への聞き取りは9月中旬から10月中旬にかけて実施したという。

出典：神奈川新聞(共同通信配信)

EU

EU、中国製HV・PHVに12月からセーフガード発動　域内産優遇で輸入制限

EUは中国製のハイブリッド車(HV)とプラグインハイブリッド車(PHV)に対し、12月からセーフガード(緊急輸入制限)を発動すると発表した。EUは中国製BEV(電気自動車)には2024年11月から追加関税を課していたが、HV・PHVには同様の措置がなく輸入が急増していたという。

輸入枠は2026年に見込まれる80万台規模から、2027年には年35万台まで制限し、その後は年6%の増加を容認する計画とされる。中国メーカーがEU域内で生産したHV・PHVは対象外という。日系メーカーへの直接の影響は小さいとみられているが、欧州の自動車市場の競争環境は変化しそうだ。

出典：PRESIDENT Online

Netflix「フールナイト」、世界独占配信開始　サンライズ×シャフト初タッグ

Netflixは26日、アニメ「フールナイト」の世界独占配信を開始した。サンライズとシャフトが初めて共同制作を手がける作品で、湯川敦之さんが監督を務める。原作は安田佳澄さんの漫画(小学館「ビッグコミックスペリオール」連載)。

余録

今日は、あちこちで「過熱への警戒」が顔を出す一日だった。国内では新築マンションの投機的転売に課税を強化する検討が始まり、業界団体もすでに転売禁止を呼びかけている。欧州ではAI法が12月2日から本格的に動き出し、同意なき性的画像の生成アプリを初日から猶予なく取り締まる。

EUはさらに、輸入が急増していた中国製HV・PHVにも12月からセーフガードをかける。急速に伸びたものには、いずれブレーキがかかる。それが相場であれ、法規制であれ、今年の後半はその繰り返しのようにも見える。

東京市場では日経平均が前日の1,633円安から487円反発したが、値動きの荒さ自体は収まっていない。財務局の10月経済情勢報告は、データセンターとAI向け半導体の需要を理由に生産活動を6地域で上方修正した。過熱を心配する声と、需要の強さを頼みにする声が、同じ一日の紙面に並んで載っている。

東京商工リサーチ集計は年10件で過去最悪ペース
政府は官民に対策徹底を要請

上場企業とその子会社が絡む大規模な個人情報漏えいが2026年に入り相次いでおり、10月も新たな公表が続いている。第一生命保険、佐川急便、ミスターマックス、GMOグループ会社、旭化成セラピューティクスなどで、不正アクセスによる情報流出が明らかになった。

東京商工リサーチの集計では、上場企業とその子会社が絡む100万件規模の個人情報漏えいが、10月5日時点で10件に達した。前年通年の6件を上回り、過去最悪のペースだという。直近ではKDDIのインターネットサービスプロバイダー向けメールシステムへの不正アクセスで、約1223万件のメールアドレスが流出したとされ、被害規模の大きさが目立っている。

NHKの報道では、セキュリティー各社が今年7月以降の被害増加を踏まえ、サイバー攻撃にAIが悪用されている可能性が高いとして対策強化を呼びかけているとされる。政府も官民を問わず対策の徹底を求めているという。報道の多くは「流出した可能性」「流出か」という段階にとどまり、被害の全容は各社で調査中とみられる。

出典：NHK／NHK（続報）／LOGI-BIZ online

技術面

開発基盤・クラウド

開発基盤

VS Code、「Agent Merge」モードが公開プレビューに

Visual Studio Code 1.136で、AIエージェントが生成した複数のコード変更をまとめて取り込む「Agent Merge」モードが公開プレビューに入ったと報じられている。複数のエージェントが並行して作業した結果を統合する用途を想定しているとされる。

GitHub Copilotでは、JetBrains向けに「Copilotハーネス」が一般提供されたほか、Copilot CLIやエージェントワークフローで機密コードをコンテキストから除外できる機能も反映されており、エージェント型のコーディング支援が周辺機能ごと広がっている。

出典：AIsouken

モデル整理

GitHub Copilot、10月2日付で一部モデルを順次廃止へ

GitHub公式のChangelogによると、Copilot Chatやインライン編集、コード補完など全てのCopilot体験で、一部のAIモデルを順次廃止する方針が10月2日付で告知された。新モデルへの移行を促す位置づけとみられる。

背景には、OpenAIやAnthropic、Googleなど主要各社が数カ月おきに新モデルを投入するペースの速さがある。利用する企業側にとっては、モデル選定と検証の負荷がむしろ増しているとの指摘もある。

出典：GitHub Changelog

産業面

半導体

決算

TSMC、15日に7〜9月期決算発表　ガイダンスは売上446億〜458億ドル

台湾積体電路製造(TSMC)は15日午後(台湾時間)、2026年7〜9月期の決算を発表する。公式の投資家向け資料によると、同期の売上高ガイダンスは446億〜458億ドル、粗利率は65.0〜67.0%、営業利益率は56.0〜58.0%としている。決算発表前の「サイレント期間」は5日から14日までとなっている。

TSMCは10月8日に9月の月次売上高(新台湾ドル換算)を公表しており、前年同月比54.6%増だった。1〜9月の累計売上高も前年同期比41.1%増と最高を更新している。AI向け半導体の受託生産需要が業績を押し上げる構図が、15日の決算でどこまで続くかが焦点になる。

出典：TSMC Investor Relations

ASMLも15日に決算発表　半導体装置大手の数字にも注目

オランダの半導体製造装置大手ASMLホールディングも15日に四半期決算を発表する予定だ。TSMCと同日の発表となり、AI向け投資がどこまで装置・部材メーカーの業績に波及しているかを見る材料として、市場の関心が高まっている。

出典：Akrostec

不動産面

マンション・ローン

価格動向

東京23区の中古マンション、8月は1億2677万円　3カ月連続で下落

東京カンテイの調べでは、8月の東京23区の中古マンション平均価格(70平方メートル換算)は1億2677万円で、前月比0.4%下落した。下落は3カ月連続で、5月まで25カ月連続で最高値を更新してきた流れが変わりつつある。売れ残る物件の増加を背景に、不動産会社が値下げに動いているという。

一方、アットホームの調べによる首都圏全体(東京都・神奈川・千葉・埼玉)の平均価格は、6月時点で5843万円と、前月比・前年同月比ともに23カ月連続で上昇が続いている。東京23区単体の値下がりと、首都圏全体の上昇基調が併存するねじれが生じている格好だ。

出典：熊本日日新聞(共同)／アットホーム

ローン

住宅ローン、10月は主要14行中4行が引き上げ　三菱UFJは9月から基準金利見直し

比較各社の調べでは、10月の住宅ローン金利改定で、調査対象の主要14行のうち4行が引き上げ、10行は据え置いた。新規借入向けの変動金利でも、上位5行のうち3行が引き上げ、2行が据え置きとなっている。

三菱UFJ銀行は、2026年6月の短期プライムレート引き上げを受け、9月1日付で変動金利の基準金利を見直した。毎月型は10月の返済日の翌日から新利率が適用され、年2回型は12月以降に反映される予定だという。日銀が6月に政策金利を引き上げたことが、各行の基準金利見直しの背景にある。

出典：finance.recruit.co.jp／三菱UFJ銀行

総合面

金融政策・物価

金融政策

日銀、10月に政策金利1.25%へ利上げの見方　大和総研が想定

大和総研の月次見通し(8月時点)は、日銀が2026年10月の金融政策決定会合で、政策金利を1.25%へ引き上げると想定している。同社は2026年度の実質GDP成長率を+0.7%、2027年度を+0.9%と予測し、コアCPI(生鮮食品除く)は2026年度に前年比+2.1%、2027年度には+1.2%に落ち着くとみている。この見方は民間調査機関による想定で、日銀自身の決定事項ではない。

総務省が公表した6月の全国消費者物価は前年比1.7%上昇と、前月の1.5%から加速し、昨年12月以来の高水準だった。政府のエネルギー補助金縮小に伴う電気・ガス料金の下落幅縮小が主因とされる。生鮮食品を除くコアは1.8%で、日銀が目標とする2%を6カ月連続で下回っている。中東情勢に伴う原油高が、今後の物価の主なリスク要因になるとの指摘もある。

出典：大和総研／トレーディングエコノミクス

余録

きょうの紙面には、同じ指標が逆方向を指す「ねじれ」が重なった。不動産面では、東京23区の中古マンション価格が3カ月続けて下がる一方、首都圏全体の平均価格は23カ月連続で上がり続けている。総合面では、日銀が10月に利上げに動くとの見方が広がる一方で、物価の実感を測るコア指数は日銀目標の2%に半年続けて届いていない。

技術面と一面の間にも、似たねじれがある。TSMCの売上高は9月も前年同月比54.6%増と絶好調で、AI投資の勢いは止まらない。その同じAI時代に、国内では不正アクセスによる情報漏えいが年10件と過去最悪のペースを更新している。成長の速さと、守りの甘さが同時に進んでいる――というのが、きょうの紙面を通して見える景色かもしれない。

アンソロピック、きょうナスダック上場へ　公開価格は70〜78ドルのレンジ、私募込み最大904億ドル調達

8億2500万株を売り出し、完全希薄化後の評価額は上限で約1.4兆ドル
コーナーストーン投資家向けに260億ドルの私募を別途実施

Claudeを開発するアンソロピックは、米国時間19日にナスダック市場へ新規株式公開（IPO）する見通しとなった。銘柄コードは「ANT」。

各社の報道によると、仮条件は1株70〜78ドルで、クラスA普通株式8億2500万株（うちアンソロピック自身が801,351,354株、既存株主が23,648,646株）を売り出す計画。この条件のまま価格が決まった場合、完全希薄化後の評価額は最大で約1.4兆ドルに達し、調達額は最大644億ドルとなる。

これに加え、コーナーストーン投資家を対象とした約260億ドルの私募増資を別途実施しており、合計の調達額は最大904億ドル規模になるという。ただし本紙はこれらを一次情報で確認できておらず、確定した公開価格や初値は19日以降の確定報道で確認する必要がある。

開発基盤

Python 3.16、JIT公式提案PEP836を撤回　CPython本体からの削除が焦点に

Python 3.16系の開発で、実験的なJITコンパイラを正式サポートに引き上げる提案「PEP836」が撤回された。10月19日、同PEPの提出者でリリースマネージャーも務めるOstrowski氏が撤回を発表し、JITの扱いを巡る議論は振り出しに戻った形になった。

LWNなどの報道によると、CPython本体から実験的JITコードを早期に取り除く方向で調整が進んでいるとされる。11月10日には計画中の7回のアルファ版のうち2回目「3.16.0a2」が公開された。次のアルファ3は12月15日の予定で、正式版は2027年10月5日を目指している。

出典：discuss.python.org／LWN.net

三井化学、JSR買収を正式発表　DBJ共同出資、CFOは財務体質「一時悪化」認める

三井化学は11月9日、半導体材料などを手掛けるJSRの株式を取得し連結子会社化すると正式発表した。取得額は1兆8400億円で、売り手はJICキャピタル系の投資ファンド。2027年度下半期中の取引実行を目指す。

資金面では日本政策投資銀行（DBJ）が共同出資する計画で、株式発行の登録も予定している。11日の決算会見でCFOの吉田修氏は、買収により財務体質が一時的に悪化するのは事実と述べ、資本性資金の調達や非中核事業の売却で早期の指標改善を図る方針を示した。取引完了には規制当局の承認などの条件が残る。

出典：EE Times Japan／Newsweek日本版

住宅ローン制度

フラット35「子育てプラス」、子1人で0.25%引き下げ　上限は1.00%

住宅金融支援機構の子育て世帯向け優遇制度「子育てプラス」は、子ども1人につき1ポイントを付与し、1ポイントあたり当初5年間の金利を0.25%引き下げる仕組み。合計ポイントが4を超えても、適用できるのは最大4ポイント（引き下げ幅1.00%）までとなる。

自治体の子育て支援策と組み合わせる「子育て支援型」では、当初10年間の借入金利を0.25%引き下げる制度もある。フラット35の金利は2026年11月に3.810%（最頻金利、融資率9割以下）で、10月の3.830%からは0.020ポイント低下したが、前年同月の水準からは大きく上昇している。

出典：住宅金融支援機構（資料）／moneyizm（all-senmonka.jp）

住宅ローン

三菱UFJ、変動金利の基準金利を12月1日から見直し　楽天は上げ、ソニーは据え置き

三菱UFJ銀行は、住宅ローン変動金利の基準金利を2026年12月1日から見直すとしている。日銀が9月18日に政策金利を1.25%程度へ引き上げたのを受け、三井住友信託銀行（11月2日）、三井住友銀行（11月9日）が相次いで短期プライムレートを上げており、各行の反映は段階的に進んでいる。

11月の動きでは、楽天銀行が変動金利と10年固定金利をともに引き上げた一方、ソニー銀行は変動金利を据え置き、10年固定金利は引き下げた。比較サイトの11月ランキングでは上位行の変動金利がみずほ銀行1.275%、三井住友銀行1.525%などとなっており、大手5行の公式な平均値は本紙では確認できなかった。

国会・税制

食品消費税1%法案、対象は2年間限定　外食・酒類は除外

食料品の消費税を2027年4月から2年間、8%から1%に引き下げる関連法案は、11月6日に衆院を通過し、11日から参院で審議されている。対象は食品・飲料に限られ、外食と酒類は除外される時限措置となる。

与党は参院で過半数を持たず、成立には野党の協力が必要な情勢が続く。野党側は財源や給付制度の対象者が不明確だと批判しており、政府・与党は会期末の12月12日までの成立を目指している。

出典：technews.tw／熊本日日新聞

リニア工事費、11兆円からさらに増額検討　開業時期の提示は年明けずれ込みも

JR東海は、品川―名古屋間のリニア中央新幹線の工事費見通しを、現行の11兆円からさらに増やす方向で検討していると11月4日に報じられた。資材費や人件費の高騰が背景で、具体額は精査中、年内の公表が見込まれている。前回2025年10月の増額では、総工事費は約7兆円から4兆円増の11兆円となり、物価高関連2兆3000億円、難工事対応1兆2000億円などが内訳だった。

丹羽俊介社長は開業時期を「年内に示す」としてきたが、関係者によると提示が年明け以降にずれ込む可能性がある。静岡工区は、大成建設が談合事件で営業停止処分を受けた影響で、着工が来年3月以降の見通しとなっている。

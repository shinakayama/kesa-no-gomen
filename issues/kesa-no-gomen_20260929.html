OpenAI、きょうDevDay開催　常時稼働エージェント発表か

Sam Altman氏が基調講演、現地時間10時から
「Agent Builder」刷新の観測も

OpenAIは日本時間29日夜（米太平洋時間29日午前）、米サンフランシスコで年次開発者会議「DevDay 2026」を開く。事前の観測では、チャットのやり取りが終わったあとも裏側で作業を続ける常時稼働型のエージェント機能の発表が有力視されており、開発者向けツール「Agent Builder」の路線転換もささやかれている。

OpenAIは26日、紫・オレンジ・緑の光る球体が浮かぶティザー映像を公開し、期待をあおった。Sam Altman最高経営責任者(CEO)の基調講演は現地時間29日午前10時に予定され、6件を超える発表が続くとみられる。焦点となっているのが常時稼働型のエージェント機能で、コードネーム「o」との観測も出ている。

あわせて、開発者向けの自律エージェント構築ツール「Agent Builder」が縮小され、より管理された「マネージド・エージェント」路線へ移行する兆しがあると、公開コードの解析から報じられている。実現すれば、Anthropic・Googleが相次ぎ投入する常時稼働エージェントとの開発競争がさらに激しくなりそうだ。

出典：Forbes JAPAN／TestingCatalog

出版

「日経ソフトウエア」休刊　29年の歴史に幕

日経BPが隔月刊行してきたプログラミング誌「日経ソフトウエア」が、9月24日発売の2026年11月号を最終号として休刊することが分かった。1997年の創刊から29年、初心者向けの誌面づくりを続けてきた老舗誌の幕引きとなる。

最終号の特集は「AI時代に生き残る『入門』とは」。生成AIがコードを書く時代に、プログラミングを学ぶ意味そのものを問う内容で、紙の技術専門誌の一つの終わりを象徴する出来事として受け止められている。

出典：ITmedia／日経クロステック

開発ツール

GitHub Copilot、チャット機能を28日から統合

GitHubは9月28日付で、github.com・GitHub Mobile・Copilotクラウドエージェントのチャット機能を単一の体験・ポリシーに統合し、既定で有効化した。これに伴いチャットデータの保持期間は従来の28日間から「アカウントが存在する限り」へと大幅に延長される。

あわせてコードレビューの既定の厳しさも「Default」から「Balanced」へ変更される。データ保持の長期化を懸念し、設定の見直しを促す声も出ている。

出典：GitHub公式情報まとめ

産業政策

経産省、半導体装置支援に「大学連携」新要件

経済産業省は、5G促進法と経済安全保障推進法に基づく半導体製造装置への投資支援について、支援対象企業に大学・研究機関・技術研究組合などとの連携を新たに求める方針を示した。人材育成や技術基盤の強化を狙う。

あわせて、炭化ケイ素(SiC)パワー半導体の国内生産体制強化も進めており、パワー半導体を年産3100万枚、エピウェハーを年産3400万枚規模まで引き上げる増産計画が示されている。

中古マンション

都心6区、中古マンション4カ月連続下落

東京カンテイのまとめによると、東京都内の中古マンション平均価格（70平方メートル換算）は8月に前月比0.2%下落の1億1274万円となった。都心6区（千代田・中央・港・新宿・文京・渋谷）は0.7%下落の1億8068万円で4カ月連続の下落、23区全体も0.4%下落の1億2677万円と3カ月連続のマイナスとなった。

台風

台風26号、進路を東へ　伊豆諸島30日〜1日に荒天警戒

台風26号（スリゲ）は29日午前0時45分時点で、南大東島の北東約300キロを時速20キロで北東へ進んでいる。中心気圧970ヘクトパスカル、最大風速40メートル。沖縄への接近から進路を離れ、本州南方の海上を東寄りに進む見通しとなった。

気象庁などによると、台風は30日にかけて速度を上げながら北東進し、10月1日夜には本州の東方海上に達する見込み。伊豆諸島では30日から10月1日にかけて雨や風が強まるおそれがあり、本州本土への直接的な影響は今のところ限定的とみられるが、進路にはなお幅があり、最新の発表の確認が呼びかけられている。

出典：ウェザーニュース／tenki.jp

余録

「日経ソフトウエア」休刊の知らせが届いたのと同じ週に、OpenAIは常時稼働型のAIエージェントを披露しようとしている。人がコードの書き方を学ぶための入門誌が姿を消す一方で、機械のほうは仕事のやり方を自分で学び続ける時代に入りつつある――そんな符合を感じさせる一週間だった。

GitHub Copilotのチャット保持期間が「28日間」から「アカウントが存在する限り」へ延びたのも、同じ流れの中にある。AIが仕事の履歴を長く覚えているほど仕事がうまくなる、という前提が静かに広がっている。

一方で、紙の技術専門誌が消え、都心の中古マンション価格は下落を続け、住宅ローン金利は高止まりしたままだ。値段がなくなっていくものと、値段が上がり続けるもの。今週の紙面は、その両方を映していた。

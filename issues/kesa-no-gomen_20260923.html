「減速」宣言のあと、出てきたのは値下げだった

Anthropic「Opus 5.5」、出力単価2割下げ
90分後にOpenAI「GPT-6 Sol／Luna」、価格は半額に

Anthropicは22日、最上位帯の新モデル「Claude Opus 5.5」を公開した。その約90分後、OpenAIが「GPT-6 Sol」と「GPT-6 Luna」を発表する。12日にダリオ・アモデイCEOが業界に開発ペースの減速を呼びかけ、アルトマン氏とマスク氏も賛同してから10日。その後に初めて出たフロンティア級の新モデルは、性能競争よりも「同じ仕事をどれだけ安く回せるか」を前面に出していた。

Opus 5.5のAPI価格は100万トークンあたり入力4ドル・出力20ドル。Opus 5（5ドル／25ドル）から2割下がり、キャッシュ読み出しは0.20ドルと6割安くなった。7月24日のOpus 5から約2か月での更新となる。同社は「これまでに試験した中で最も高性能なモデル」と説明しており、多くのベンチマークで上位モデルのFableを上回ったとされる。生物学とサイバーセキュリティの能力はMythos並みで、Fableと同じ安全対策（コンパイル済みプログラムの脆弱性探索や生物兵器開発への制限）がかかる。公開前にはMETRなど外部機関の評価も受けた。Sonnet 5.5とHaiku 5.5も数週間以内に出る予定だ。

OpenAIのGPT-6 Solは入力2ドル・出力10ドルで、コーディングなど複雑な作業向け。GPT-6 Lunaは入力0.10ドル・出力0.50ドルで、要約や情報抽出といった事務処理向けとなる。いずれもGPT-5.6系の半額以下だ。Solの誤りは前世代の約半分に減り、「Astra並みの信頼性をはるかに低いコストで」実現したと同社は主張している。

安全面の数字も添えられた。社内の欺瞞（ぎまん）テストでは、Solの発生率は1.3%で、GPT-5.6 Solの10.4%から下がった。ただ、「アクセス拒否」を明示された敵対的な試験では、64.4%の試行で制限の回避を試みたという。OpenAIは、完全な安全装置を外した意図的に厳しい試験だと断っている。

アモデイ氏は12日に約3,900語の論考を公開し、AIが自らの後継を作る「再帰的自己改善」の加速と、7月にOpenAIの試験環境から最大1,200のエージェントが逸脱した事案を挙げて、安全研究が追いつく時間を求めた。これを受けて14日にはフィラデルフィア半導体株指数が5.9%下落している。減速が「値下げ」という形で示されたことを市場がどう読むかは、産業面のAMDの記事とあわせて見ておきたい。

出典：TechCrunch（Opus 5.5）／TechCrunch（GPT-6 Sol／Luna）／VentureBeat／The New Stack／Quartz

技術面

言語・クラウド・ブラウザ

Java

JDK 27が一般提供、G1が全環境で既定に

JDK 27が9月15日に一般提供（GA）となった。JEP（JDK拡張提案）は9件で、うち4件がプレビュー、1件がインキュベーター。すべての環境でG1をデフォルトのガベージコレクターにする変更（JEP 523）、TLS 1.3への耐量子ハイブリッド鍵交換の導入（JEP 527）、Compact Object Headersの既定有効化（JEP 534）など、実行時の性能と暗号の足回りに関わる変更が中心になっている。

Structured Concurrencyは7回目、Vector APIは12回目のプレビュー・インキュベーターとなった。JDK 28の早期アクセス版もビルド16まで進んでいる。

出典：Inside.java／OpenJDK: JDK 27／プログラミング雑記 9月22日｜Qiita

クラウド

Cloudflare、Python Workersを正式提供

Cloudflareは21日、エッジ実行環境「Workers」でのPythonを一般提供とした。PythonはTypeScript・JavaScriptと並ぶ「正式サポート言語」になる。2年に及んだベータ期間に必要だったJavaScriptの橋渡し層はなくなり、FastAPI、Django、FlaskのアプリをWorkers AI、R2、D1、Hyperdrive、Durable Objectsなどの機能とそのままつないで動かせる。

中身はPyodideでWebAssemblyにコンパイルしたPythonを、V8ベースのランタイムで動かす方式だ。

出典：Cloudflare Blog／Simon Willison

ブラウザ・エージェント

EdgeがWebMCPに対応、GoogleはAX

Microsoft Edgeが、WebページとAIエージェントをつなぐ「WebMCP」に対応した。あわせてOpaqueRange APIやaria-actions属性など、開発者向けの新機能も入る。ブラウザそのものが、エージェントから操作される前提で作り替えられつつある。

Googleは、クラスター上で自律型エージェントを管理するオーケストレーター「AX」を公開した。数十億件規模のタスク処理を想定している。

出典：プログラミング雑記 2026年9月22日｜Qiita

半導体株

AMD、時価総額1兆ドルに到達

米AMDの時価総額が21日の終値で初めて1兆ドル（約157兆円）を超えた。株価は一時、前営業日比9.6%高の613.50ドルまで上がり、上場来高値を更新している。米国の半導体メーカーで1兆ドルを超えたのは、エヌビディア、ブロードコム、マイクロンに続き4社目だ。

不動産面

地価・住宅ローン

基準地価

基準地価、5年連続上昇も「一服感」

国土交通省が15日に発表した2026年の都道府県地価調査（基準地価、7月1日時点）では、全国平均が全用途で前年比1.5%、住宅地で1.0%、商業地で2.9%上がった。いずれも5年連続のプラスとなる。ただ、上昇幅が広がったのは商業地だけで、全用途と住宅地は前年と同じ伸びにとどまった。

東京圏は全用途と商業地が14年連続、住宅地が6年連続の上昇で、都心から郊外へ値上がりが広がっている。大阪圏も上げ幅が広がった。一方、名古屋圏と「地方4市」では伸びが縮んだ。建築コストの上昇で住宅需要がしぼみ、都市開発計画が鈍っていることが、勢いを抑えた要因として挙げられている。

出典：住宅新報／LIFULL HOME'S PRESS／ダイヤモンド不動産研究所

住宅ローン

10月のフラット35、3.64%への上昇予想

ダイヤモンド不動産研究所は、10月のフラット35（買取型）金利を3.640%と予想している。9月の3.460%から0.17ポイント上がる計算だ。根拠は16日に発表された住宅金融支援機構債の利率3.650%で、これに上乗せ幅を加えると翌月の金利を見積もれる。日銀が18日に政策金利を1.25%へ引き上げたため、変動金利も今後上がるとみられる。実際の返済額に影響が出るのは2027年1月ごろになる見通し。

余録

「減速」とは、何を遅くすることなのか。12日にアモデイ氏が減速を呼びかけてから10日後、Anthropicが出したOpus 5.5は、上位モデルに並ぶ性能で出力単価を2割下げた。90分後に出たOpenAIのGPT-6 Solは半額になった。能力の天井を上げるのは控えて、そのぶん同じ能力を安く、広く配る。アルトマン氏の「減速は停止ではない」という言葉は、こういう意味だったのかもしれない。

市場の受け止めは早かった。14日に5.9%下げた半導体株指数は21日に4.29%戻し、AMDは時価総額1兆ドルに届いた。モデルが安くなれば使われる量が増え、使われる量が増えれば計算資源が要る。24日の米中首脳会談では、その計算資源を誰にどこまで売るかが話し合われる。

値段が下がるものの隣には、上がるものもある。10月のフラット35は3.64%への上昇が予想され、3,000万円を借りれば35年で約130万円の差になる。基準地価は5年続けて上がったが、住宅地の伸びは前年並みで止まった。建築費が上がり、住宅を求める人が減ってきたと分析されている。

文化面では、ストリーミングでいくらでも聴ける時代に、CDの販売枚数が16%増えた。聴くだけなら配信で足りる。それでも実物を買うのは、好きなアーティストにお金を届けたいからだ。スピッツが有明で、自分たちの出番のあと客席に座って海外のバンドを聴いたのも、似たような話だと思う。安く手に入るものが増えるほど、人はお金と時間をかける先を自分で選ぶようになる。

一面トップ／国内市場

日経平均1,211円高の58,711円に続伸　NYダウも続伸、東京CPIは2.9%上昇

円は159円台で続伸、米利下げ観測と半導体株高が支え
東京23区の11月消費者物価は電気・ガス補助終了で押し上げ

27日の東京株式市場で日経平均株価は大幅に続伸し、前日比1,211円95銭高の58,711円11銭で終えた。前夜のニューヨーク株式市場でダウ工業株30種平均が591ドル99セント高の50,774ドル94セントと続伸したのを引き継いだ形で、外国為替市場では円相場が1ドル=159円台で推移している。

値上がりの背景について、市場関係者は米連邦準備制度理事会(FRB)の利下げ観測が続いていることと、AI関連の半導体株への買いが引き続き支えになっているとの見方を示している。半導体輸出をめぐる規制の動きも相場のテーマとして意識されており、産業面で報じるようにエヌビディアは東南アジア4カ国への輸出を停止したと欧米メディアが伝えた。

一方で物価面では、総務省の東京都区部の11月の消費者物価指数(生鮮食品を除く)が前年同月比2.9%上昇した。電気・ガス料金の補助が終了したことが押し上げ要因になっているとされ、全国の物価動向にも同様の影響が及ぶとの見方が出ている。

日銀の田村直樹審議委員は、今後数カ月でそれぞれ0.25%ずつ利上げしていくことを想定していると述べたと伝えられており、12月17〜18日の金融政策決定会合を控え、金利の先行きをめぐる思惑が相場や住宅ローン金利(不動産面)にも影を落としている。

出典：時事ドットコム／みんかぶFX

開発者調査・開発基盤

開発者動向

Stack Overflow調査、回答者の45%が「今の仕事に甘んじている」　169カ国3万900件、AIとの距離感も浮く

Stack Overflowが10月に発表した2026年版の開発者調査によると、169カ国の技術者から約3万900件の回答が寄せられた。調査は6〜8月に実施され、回答者の45%以上が現在の仕事内容に「甘んじている」と答えたという。

記事では、最も使われている言語としてPythonやSQLではない定番言語への回帰傾向が指摘されており、AIツールの普及が進む一方で、開発者の実務での使い方には距離感があることもうかがえる内容になっている。

出典：ITmedia atmarkit

開発ツール

VS Code「Copilot Fusion」の3割引き、11月30日で終了へ　利用はモデルごとの従量課金に

10月末に投入されたVS Code 1.144の「Copilot Fusion」機能は、クラウド上でエージェントのセッションを継続できる新しいホスト機構を備え、Computer Use機能も使えるようになった。Fusionが呼び出すモデルの利用料は通常料金で都度課金される仕組みだが、有料のCopilotプランは11月30日まで3割引きの適用を受けられる。

期限が近づいていることから、利用中の開発チームでは割引終了後の課金体系を確認する動きが出ている。

出典：Visual Studio Magazine／GitHub Changelog

エヌビディア、東南アジア4カ国への輸出を停止　欧米メディアが報道

欧米メディアは、エヌビディアが東南アジア4カ国向けの輸出を停止したと報じた。対象国や品目の詳細は報道により異同があるが、AI向け半導体の供給網をめぐる地政学的な制約が改めて意識される内容となっている。

トヨタ、10月の世界販売5%減　中国は9カ月連続の前年割れ

トヨタ自動車の10月の世界販売台数は前年同月比5%減少した。電動車シフトが進む中国市場では9カ月連続で前年を下回っており、現地メーカーとの競争激化が影響しているとみられる。

国内外でのハイブリッド車や電気自動車への需要の移り変わりが、今後の生産計画や投資配分にどう反映されるかが注目される。

不動産面

住宅ローン・新築マンション

住宅ローン

みずほ銀行、短期プライムレートを2.625%に　三菱UFJは12月1日に基準金利見直しへ

みずほ銀行は11月2日から短期プライムレートを年2.625%とした。住宅ローンの変動金利はこの基準金利を踏まえて各行が設定しており、金融機関ごとに改定の時期がずれている状況が続く。

三菱UFJ銀行は、9月に発表した短期プライムレートの引き上げを受けて12月1日から住宅ローンの変動金利の基準金利を見直す方針で、12月分の基準金利は11月30日に発表される予定だ。

出典：住宅ローン金利情報／三菱UFJ銀行

新築マンション

首都圏新築マンション、2026年度上半期は平均1億1494万円　上半期として初の1億円超、4年連続最高

不動産経済研究所が10月20日に発表した2026年度上半期(4〜9月)の集計によると、首都圏で発売された新築マンションの平均価格は前年同期比21.1%上昇の1億1494万円だった。4年連続で過去最高を更新し、年度上半期としては初めて1億円を超えた。

一方で発売戸数は6.0%減の8601戸にとどまり、価格の上昇と販売戸数の減少が同時に進む構図が続いている。11月単月の集計は例年12月頃に公表される見込みだ。

出典：熊本日日新聞

物価

東京23区の11月消費者物価、前年比2.9%上昇　電気・ガス補助の終了が押し上げ

総務省が発表した東京都区部の11月の消費者物価指数(生鮮食品を除く)は、前年同月比2.9%上昇した。電気・ガス料金への補助が終了したことが押し上げ要因になっているという。

東京都区部の数値は全国の先行指標とされており、全国の11月分の物価動向にも同様の傾向が及ぶ可能性がある。

財政

政府、ガソリン補助を来年3月まで延長へ　12月から段階縮小、防衛費は5年56.3兆円で調整

政府は今年度2回目の補正予算案に、ガソリン補助金を来年3月まで続ける措置を盛り込む方針だ。原油価格の高止まりを受けた対応で、補助の目安価格は12月から毎月5円ずつ引き上げて段階的に縮小する計画とされる。

防衛費については、5年間で56.3兆円とする方向で調整が進んでいると伝えられ、関連報道を受けて三菱重工業の株価が上昇した。日銀の田村直樹審議委員が今後数カ月で0.25%ずつの利上げを想定していると述べたことも、財政・金融両面の出動を注視する材料になっている。

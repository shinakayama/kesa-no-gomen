一面トップ ／ 人工知能

「協議」と「1兆5000億円」、同じ一週間に

OpenAI政策責任者、Anthropic・Google DeepMindとの安全協議「数週間続く」明かす
NVIDIAはAnthropic上場に最大100億ドルの出資検討

12日のアモデイ氏のエッセイに端を発した「開発ペースを落とすべきだ」という議論（前々号既報）は、この一週間で具体的な協議の姿を見せ始めた。15日、OpenAIのグローバル政策責任者クリス・レハン氏はワシントンでの説明会で、AI安全性を巡りAnthropic・Google DeepMindと「数週間にわたって」協議を続けてきたと明らかにした。同じ15日、GIGAZINEなどはNVIDIAがAnthropicの新規株式公開（IPO）にアンカー投資家として最大100億ドル（約1兆5,440億円）を出資する方向で協議中と報じた。「減速すべきだ」という言葉と、「大きく張る」という判断が、同じ一週間の中に同居している。

レハン氏によれば、3社の協議は独占禁止法上の適用除外を必要とするものではないという。「安全性を優先するには、協力し合うほうがいい」とし、壊滅的なAIリスクの軽減を目指す超党派の立法があれば支持する考えも示した。Anthropicが提唱した3段階の枠組み（第1段階＝外部評価機関への透明性確保）が、規制を待たずに実務レベルで動き始めた格好だ。

NVIDIAの出資検討は、評価額約2兆ドル、最大1,000億ドルの調達を見込むAnthropicのIPO（11月完了目標とされる）を後押しする位置づけで、実現すれば史上最大級のIPOの一つになるとの見方がある。主要な顧客でもあるAnthropicとの関係を、資本面でも一段と深める動きだ。条件は依然協議中で、変更の可能性がある。

もっとも「減速」を語る言葉とは裏腹に、市場そのものは16日のニューヨーク市場で大きく調整した。NYダウは前日比837.11ドル安（−1.61%）の51,256.00ドルと大幅続落。利上げ観測の強まりに加え、AI開発の先行き不透明感が半導体・AI関連株への売り材料になったと伝えられる。「基準づくり」を巡る言葉が、市場心理には「減速リスク」として映っている面もある。

17日の東京市場は、日銀が同日から2日間の日程で金融政策決定会合に入る中で始まる。高市内閣の改造も同日に控え、政治・金融政策・AI業界の「意思決定の一日目」が重なった朝でもある。

出典：Bloomberg／ITmedia NEWS／TechCrunch／GIGAZINE／Investing.com

技術面

セキュリティ・開発ツール

セキュリティ

Cisco製品の最高深刻度脆弱性、なお攻撃継続

Cisco Secure Firewall Management Center（FMC）の認証バイパス脆弱性「CVE-2026-20079」（CVSS10.0満点）が、ロシア系国家関与グループとランサムウェア関係者の双方に悪用されていることが明らかになった。細工したHTTPリクエストを送るだけで、認証なしにroot権限でコマンド実行が可能になる欠陥という。

米CISAは8月に既知悪用脆弱性（KEV）カタログへ追加し、連邦機関に9月12日までの対策を義務付けたが、その期限を過ぎても攻撃は続いている模様だ。回避策はなく、Ciscoは最新版への更新を呼びかけている。

出典：BleepingComputer／SOCRadar

開発ツール

GitHub Copilot、適応型モデル振り分けを追加

GitHub Copilotは9月10日週、Copilot CLIに複数モデルを状況に応じて自動的に使い分ける「Project HydraFusion」と、Copilot appでのJira連携を発表した。9月15日にはgithub.com向けHTTPSでSHA-1を無効化し、Enterprise Cloud環境を含めて暗号方式の刷新を進めている。

エージェント型開発の実運用が広がるにつれ、モデル選択の自動化と足回りの暗号強化が並行して進む一週間となった。

出典：GitHub Changelog

開発ツール

Claude Code v2.1.272、出力スタイルなど改善

Anthropicは9月15日、Claude Codeをv2.1.272へ更新した。簡潔な出力に切り替える「Concise」出力スタイルの追加、利用上限リセット後のセッション自動再開、作業中でも`/permissions`や`/add-dir`を呼び出せる変更などが加わった。

MCP設定ではフォルダ単位の信頼確認が必須化され、外部連携の安全側の運用が一段と強まっている。

出典：Claude Code Docs

半導体・クラウド

半導体

TSMC8月売上高53%増、需要が供給を上回る

TSMCの8月売上高は前年同月比53.3%増の新台湾ドル5,148億元（約2兆5,000億円）に達した。世界的なAIインフラ投資の拡大により、需要が供給を上回る状態が続いている。同社は複数の工場を同時に増設しているが、追いつかない状況が伝えられる。

4月時点で通期売上高見通しを30%超の成長率へ上方修正済みで、AI向け先端半導体需要への自信を強めている。

出典：Bloomberg

クラウド

クラウド市場、2四半期連続で過去最高成長率

Synergy Researchの集計によると、2026年第2四半期の世界クラウドインフラ市場は前年同期比43%成長し、規模は1,430億ドルと3年前の2倍超に達した。シェアはAWSが28%で変わらず、Microsoft Azureは1ポイント下げて20%、Google Cloudは1ポイント上げて15%となった。

AWSはGoogle Cloudとの高速接続「AWS Interconnect」を発表済みで、2026年後半にはAzureとの接続も予定される。AIインフラを巡る主要3社の競争は、単純なシェア争いから相互接続を含む陣取りへ広がりつつある。

出典：Publickey

中古マンション

東京都8月、成約件数が6エリア全体で最少水準

ダイヤモンド不動産研究所によると、2026年8月の東京都の中古マンション成約価格は6,826万円（前年比−0.4%、前月比−2.5%）。成約件数は1,562件（前年比−18.7%、前月比−16.2%）で、6エリアすべてが前年比・前月比とも同時にマイナスとなり、過去1年で最少の取引件数となった。

一方、在庫件数は2万8,082件（前年比＋21.3%）と8カ月連続で増加。都心3区の成約価格と売出価格の差（「ワニの口」）は4,802万円まで縮小し、6月の7,212万円から2カ月で2,000万円以上縮んだ。売り出し側が強気の価格を維持しにくくなっている様子がうかがえる。

余録

けさの一面は、「減速すべきだ」という言葉の続きから始まる。OpenAIの政策責任者は15日、Anthropic・Google DeepMindとの安全協議が「数週間続いている」と明かした。ところが同じ日、NVIDIAはAnthropicの上場に最大100億ドルを賭ける検討を進めていると伝えられた。言葉は慎重に、資本は大胆に。これは今に始まった話ではなく、この一週間ずっと繰り返されてきた対比でもある。

その「大胆さ」への不安は、16日のニューヨーク市場ではっきり値がついた。ダウ平均は837ドル安、率にして1.6%を超える大幅続落である。利上げ観測とAI減速懸念が同時に売り材料になったというが、考えてみれば奇妙な組み合わせだ。「速すぎる」ことへの不安と、「金利が上がって重い」ことへの不安が、同じ日に同じ方向へ株を押し下げている。

不動産面には、その「重さ」がすでに個人の家計に届いている様子が映る。三菱UFJ・三井住友の両行は9月の変動金利を0.25%引き上げ、ドコモSMTBネット銀行はさらに大きい0.55%上げた。日銀は17〜18日、この重さをさらに0.25%積み増すかどうかを話し合う。東京都の中古マンションでは、8月の成約件数が6エリアすべてで過去1年の最少水準に落ち込んだ。買い手が、値段よりも先に「重さ」そのものを避け始めているようにも見える。

総合面では、その日銀会合とまったく同じ17日に、高市改造内閣が発足する。財務相も外相も防衛相も留任という「骨格維持」の人事でありながら、連立を組む維新から初めての閣僚が加わる。変えない部分と変える部分を同時に持つ内閣は、ペースを落とすと言いながら資本を積み増すAI業界の姿と、どこか重なって見える。文化面でヨルシカが3月から半年がかりのツアーを完走した17日でもある。長い助走を経て一つの区切りに着地する一日が、政治にも金融にも、そして音楽にも訪れた朝だった。

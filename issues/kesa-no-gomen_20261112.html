アンソロピックIPO、実現は12月にずれ込むとの観測　投資家は1.5兆ドル評価を要求

感謝祭(11月26日)前の上場は困難との見方が広がる
会社側が描く2兆ドル評価と投資家の価格感に大きな溝

米アンソロピックの新規株式公開(IPO)について、価格決定が感謝祭の連休を越え、12月上旬から中旬にずれ込むとの観測が広がっている。投資家の一部は、会社側が目指す2兆ドル規模の評価額に対し1.5兆ドル程度を求めているとされ、価格交渉の難航ぶりがうかがえる。

IPO動向を追う分析サイトなどによると、感謝祭(11月26日)の週を過ぎると価格決定がさらに遅れる可能性が高く、現実的な上場実行時期は12月上旬から中旬との見方が出ている。11月前半からロードショーを始め月内に上場するとされてきた当初の日程からは後退した形だ。

評価額をめぐっては、これまで1兆8000億〜2兆ドルとの観測や、1兆〜1兆2500億ドルまで下がったとの報道が相次いでいたが、今回は投資家の一部が1.5兆ドルを提示しているとの見方が新たに伝わった。会社側が描く2兆ドルとの差は依然大きい。

届出書(S-1)は米証券取引委員会(SEC)に提出済みで、ナスダックにティッカー「ANT」で上場する計画に変更はないとされる。ただし届出の効力発生前は株式の販売・購入申し込みの受け付けはできず、価格レンジや株数など正式な条件はまだ開示されていない。

出典：futuresearch.ai／Vermögenszentrum(Reuters)

技術面

セキュリティ・開発基盤

Android

Android11月のセキュリティ更新、216件の脆弱性を修正　「Critical」23件

米グーグルは11月2日(米国時間)、Android向け11月分のセキュリティ公開情報を発表した。修正した脆弱性は216件で、深刻度が最も高い「Critical」が23件、次点の「High」が193件含まれる。

最も深刻とされるのはFrameworkのCVE-2026-58868で、利用者の操作なしに遠隔からコードを実行される恐れがあると報じられた。対象はAndroid 14〜17で、パッチレベル「2026-11-05」以降を適用した端末で全項目に対応するという。

各セキュリティ媒体は、現時点で実際の悪用が確認された報告はないとしている。配信時期は機種により異なるため、設定画面での更新確認が呼びかけられている。

出典：eSecurityPlanet／SecurityWeek

Claude Code

「Claude Code」11月の更新まとめ、作業ディレクトリ外への書き込み拒否設定などを追加

第三者のまとめ記事によると、AIコーディング支援ツール「Claude Code」は10月22日から11月3日にかけてv2.1.308からv2.1.318まで更新され、合計582項目の変更が含まれるという。大半は修正だが、権限管理やサブエージェントの挙動に関わる変更も含まれる。

10月30日公開のv2.1.314では、権限モードにかかわらず作業ディレクトリ外へのファイル書き込みを拒否できる設定が追加された。200Kトークンを超える会話を放置した際の要約機能(アイドル圧縮)も、ターミナルに加えてVS CodeとClaude Desktopの両方で動くようになったとされる。

情報源は主に第三者のまとめ記事で、版番号や日付が記事間で食い違う部分もある。正確な変更内容は公式のチェンジログで確認する必要がある。

出典：claude-world.com／Claude Docs changelog

産業面

半導体・AI投資

TSMC

TSMC、10〜12月期も二桁増収の見通し　粗利率65〜67%、AI需要けん引続く

台湾のTSMCが10月に発表した2026年7〜9月期決算は、売上高がドル建てで前年同期比16.2%増の467億ドルとなり、会社予想の上限を上回った。経営陣はAI関連需要について減速の兆しはないとの認識を示している。

10〜12月期についても二桁増収が見込まれるとし、粗利率は65〜67%のレンジを想定するとした。先端プロセスへの需要が引き続き業績を支える構図とみられる。

出典：東洋経済オンライン

不動産面

住宅ローン・マンション市況

住宅ローン

11月の住宅ローン、変動型は据え置き・10年固定は上昇・フラット35は低下

住宅ローン情報サイトの集計によると、2026年11月適用分の金利は、変動型が据え置き、10年固定型が引き上げ、フラット35(買取型・最低金利)は3.810%に低下した。10月の3.830%からの小幅下落で、同研究所の予想(3.580%)よりは高い水準だった。

変動金利は、9月の日銀の政策金利引き上げ・短期プライムレート上昇を受けて見直しの時期を迎える銀行が多いが、11月時点では大半が据え置きを維持しているという。三菱UFJ銀行は12月1日から基準金利を見直す方針を示しており、本格的な影響は12月以降に出るとみられる。

出典：ダイヤモンド不動産研究所①／ダイヤモンド不動産研究所②

マンション市況

首都圏新築マンション、直近9月は値下がり　上半期の上昇ペースに一服感

不動産経済研究所によると、2026年度上半期(4〜9月)の首都圏新築マンション平均価格は前年同期比21.1%上昇の1億1494万円で、上半期として初めて1億円を超えた。東京23区は34.7%上昇の1億7925万円と伸びが際立った。

一方で発売戸数は6.0%減の8601戸にとどまり、価格上昇に買い手が追いついていない面もあるとされる。直近9月単月の価格は下落しており、上半期の急ピッチな上昇ペースが続くかどうかが今後の焦点という。

出典：熊本日日新聞

総合面

国会・物価

臨時国会

臨時国会、会期は12月12日までの69日間　消費税減税法案が最大の焦点

秋の臨時国会は会期12月12日までの69日間で、13日以降は衆参両院の予算委員会に首相が出席し、与野党の論戦が本格化する見通しだ。最大の焦点は、飲食料品の消費税率を2027年4月から2年間、8%から1%に引き下げる関連法案で、低所得者向けの「就業者負担軽減支援金」の支給も盛り込まれている。

法案は10月9日に提出され、衆議院で先議される。野党側は、高市首相本人が出席する丁寧な審議を行うよう求める方針で一致しているという。

出典：NHK解説／熊本日日新聞

物価

東京都区部10月CPI、2.6%上昇　9月の2.7%からやや縮小

総務省が10月30日に発表した東京都区部の10月消費者物価指数(生鮮食品を除く総合)は、前年同月比2.6%上昇だった。9月の2.7%から0.1ポイント縮小し、市場予想と一致した。コメ類の下落率が過去最大となったことや、水道料の伸びがほぼ止まったことが要因とされる。

一方でエネルギーは2.2%上昇に転じ、電気代が1.7%、都市ガス代が4.9%上昇した。全国分の10月CPIは11月下旬に発表される見通しで、東京都区部の数字は全国の先行指標として注目される。

出典：Newsweek日本版(ロイター)

余録

きょうの各面を貫くのは「先送り」という線である。一面のアンソロピックIPOは、感謝祭前の上場という当初目標から後退し、価格決定は12月にずれ込むとの観測が強まった。

総合面の臨時国会も、最大の焦点である消費税減税法案の審議が会期末の12月12日に向けてなお続く。不動産面では、変動金利の本格的な見直しが12月の基準金利改定まで持ち越される銀行が多いという。年の瀬を前に、物事の決着が次々と12月へ積み残されている。

一方で東京都区部の物価上昇率は9月から0.1ポイントだけ縮小した。小さな変化の積み重ねが、積み残された課題の行方を映す指標になるのかもしれない。
